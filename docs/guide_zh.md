# 代码导读（中文）

## 这个程序在做什么

模拟往地下咸水层注入 CO₂ 时，岩层里的压力怎么随时间和位置变化，并判断有没有哪里超过安全上限（岩层破裂压力的 90%）。
有 1D 和 2D 两个版本，都是单核（串行）程序，都能实时显示动画。

## 怎么运行

在项目文件夹里执行：

```bash
.venv/bin/python run_1d.py                       # 1D 交互窗口
.venv/bin/python run_2d.py                       # 2D 交互窗口
.venv/bin/python validate.py                     # 和精确解对比，图存到 results/
.venv/bin/python -m pytest                       # 自动测试
```

窗口下半部分是控制区：

| 控件 | 作用 |
|---|---|
| Play / Pause | 播放 / 暂停；播完后再按 Play 就是重播 |
| Restart | 回到第 0 年 |
| year 滑块 | 拖到任意年份；算过的结果都存着，往回拖是瞬间的 |
| speed 滑块 | 播放速度：每秒播放 0.1 到 10 年 |
| 注入速度、注入年数、渗透率、孔隙度 | 参数滑块，松手后模拟自动用新参数重新开始 |
| scenario / fault、boundary、method | 场景、边界、算法，选完自动重新开始 |
| map shows（只有 2D） | 地图显示：压力升高（对数色标）/ 压力（线性色标）/ 岩石渗透率 |

命令行选项只是设定打开窗口时的初始值，比如 `run_2d.py --scenario channel`。
加 `--save results/xxx.gif` 就不开窗口，直接存成动画文件。

## 文件地图

| 文件 | 干什么 |
|---|---|
| `co2sim/parameters.py` | 所有物理参数（φ、k、μ、cₜ、深度、安全上限），全部写在这一个地方 |
| `co2sim/wells.py` | 井：公式里的 q。设置位置、每年注入多少百万吨、什么时候开和关 |
| `co2sim/finite_volume.py` | 1D 和 2D 共用的小工具：两个格子之间"管子有多粗"（T）、组装矩阵 |
| `co2sim/model_1d.py` | 1D：把岩层切成一排格子 |
| `co2sim/model_2d.py` | 2D：把岩层切成一张网格（从上往下看） |
| `co2sim/permeability.py` | 造岩石：加断层、做不均匀的岩石 |
| `co2sim/solvers.py` | 时间推进：怎么从这一刻算到下一刻（三种方法） |
| `co2sim/analytical.py` | 精确解公式，用来检查程序算得对不对 |
| `co2sim/plots.py` | 画 1D 和 2D 的图 |
| `co2sim/interactive.py` | 交互窗口：播放、暂停、重播、调速度、改参数 |
| `co2sim/animation.py` | 把动画存成 .gif / .mp4 文件 |
| `run_1d.py`, `run_2d.py` | 运行入口。窗口里能调的参数在 Settings 里；网格大小等固定设置在文件最上面 |
| `validate.py` | 精度检查、收敛性研究 |
| `tests/` | 自动测试 |

建议的阅读顺序：`parameters.py` → `model_1d.py` → `solvers.py` → `run_1d.py`。看懂 1D 之后，`model_2d.py` 只是"左右邻居"再加上"上下邻居"。

## 一个时间步里发生了什么

和之前的水桶比喻完全一样：

1. 把岩层切成很多格子（桶），每个格子存一个数：Δp = 压力 − 原始压力。
2. 相邻两格之间，水从压力高的流向压力低的：
   `流量 = T × (左边的 Δp − 右边的 Δp)`。T 就是"管子有多粗"，由 k、μ 和格子大小决定。
3. 每个格子：`净流入 = 流进来的 − 流出去的`。
4. 井所在的格子再加上井打进来的量（q）。
5. `新的 Δp = 旧的 Δp + dt × (净流入 + 井) ÷ storage`。
   storage = φ × cₜ × 格子体积，表示压力每涨 1 Pa 能多塞进去多少（桶有多胖）。

第 2、3 步对应 `model_1d.py` 里的 `net_inflow`，核心只有几行：

```python
flow_right = self.face_transmissibility * (dp[:-1] - dp[1:])  # 每个界面向右流多少
inflow[:-1] -= flow_right   # 界面左边的格子失去这么多
inflow[1:] += flow_right    # 界面右边的格子得到这么多
```

## 公式和代码的对应

| 公式 | 意思 | 代码 |
|---|---|---|
| φ cₜ ∂p/∂t | 压力涨多快 × 能塞多少 | `model.storage` |
| ∂/∂x( k/μ ∂p/∂x ) | 邻居流进来的净量 | `model.net_inflow(dp)` |
| q | 井打进来的 | `model.source(t)` |

## 三种时间推进方法

| 方法 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| explicit（显式欧拉） | 用这一刻的压力算流量 | 代码只有一行 | dt 必须很小（2D 默认约 0.1 天），否则数值会爆炸 |
| implicit（隐式/向后欧拉） | 用下一刻的压力算流量，每步解一个方程组 | dt 多大都稳定（默认 18 天一步） | 时间上只有一阶精度 |
| crank-nicolson | 两者取平均 | 时间上二阶精度，更准 | 井突然打开时，dt 太大会在井附近振荡 |

默认用 implicit。2D 模拟 30 年：显式要 10 万步、约 16 秒；隐式 600 步、约 1 秒。

## 边界条件

- `open`：岩层在模型边界外还继续延伸，边界外的压力一直等于原始压力，所以压力可以"漏"出去。
- `closed`：边界封死，一滴水也出不去，压力只能越积越高。

## 动画怎么看

- 颜色：深蓝 = 没受影响，黄色 = 接近安全上限，红色 = 超过上限。
- 2D 左边的地图默认用对数色标显示压力升高，所以离井十几公里外的小变化也看得见（压力传得比 CO₂ 本身远得多）。用 map shows 可以切换成线性色标或岩石渗透率。
- 2D 右边那张图是"整个岩层里最高的压力"随时间的变化，红色虚线是安全上限，橙色背景是注入期。
- 标题变红，说明某处压力超过上限，在现实中意味着岩层可能被压裂。

## 怎么知道算对了（validate.py）

- 和精确解对比：1D 误差约 0.01–0.1%，2D（Theis 解）误差约 0.1%。
- 格子边长减半，误差变成 1/4（二阶收敛）。
- 时间步减半：implicit 误差减半（一阶），crank-nicolson 误差变成 1/4（二阶）。
- 封闭岩层里，存进去的总量 = 井打进去的总量（tests 里自动检查）。

## 目前的简化

- 只算压力，把地下当作一种流体，所以看不到 CO₂ 本身跑到了哪里。
- 岩层水平、厚度不变，不考虑重力。
- 井所在格子的值是整个格子的平均压力，比井筒里的真实压力低。
- 1D 是一条直的带子，不是以井为圆心的径向 1D。
